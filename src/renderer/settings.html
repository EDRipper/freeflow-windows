Get started

FreeFlow turns speech into text using an OpenAI-compatible provider. Add a free Groq API key below and you're ready to dictate.

  1. Open console.groq.com/keys in your browser.
  2. Create a free account if you don't already have one.
  3. Click Create API Key, copy it, then paste it below.
